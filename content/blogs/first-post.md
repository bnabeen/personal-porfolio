Welcome to the blog! This is the first post powered completely by local Markdown files.

## Why Markdown?

Storing posts as Markdown files directly in the codebase provides clear advantages:

1. **Zero Database Overhead:** No external connections to manage, zero latency, and no database downtime.
2. **Version Controlled:** Every edit, commit, and draft is versioned alongside the code.
3. **Instant Static Generation:** Next.js compiles the markdown files during build time for maximum speed.
